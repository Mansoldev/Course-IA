Agente: El rasgo que define a los agentes es su capacidad para elegir el mejor orden de acciones para resolver un problema dado un conjunto de herramientas

COMPONENTES DE UN AGENTE:

1 Modelo de lenguaje (LLM)

2 Tools (Herramientas que puede usar)

3 Prompt de agente (Plantilla de razonamiento, guía al llm patron de pensamiento)

4 Memoria
